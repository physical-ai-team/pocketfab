# C2 Preprocessing — 담당: 조아람

프레임 전처리와 과자 후보 박스 검출을 맡는다. 찾은 박스가 C3의 SAM 2 프롬프트가 된다.
스펙: [docs/api-spec.md](../docs/api-spec.md) 4장 ②, 7.1

## 파일
| 파일 | 내용 |
|---|---|
| `app/preprocess.py` | `preprocess()`(리사이즈 → 블러 → CLAHE), `detect_boxes()`(색으로 Otsu 이진화 → 닫힘·열림 → 윤곽선 → 과자 아닌 덩어리 제거 → 과자 크기로 박스 넓히기) |
| `app/main.py` | 서버 (C1에서 받아 C3로 전달). 건드릴 필요 없음 |
| `tests/test_preprocess.py` | 박스 검출 테스트: 과자 모두 찾기, 반사된 밝은 영역·가는 띠 버리기, 가장자리가 어두운 과자의 박스 크기, 화면 끝 과자 남기기 (`pytest`) |

## 밝기가 아니라 색으로 나누기 (LAB b 채널)
처음에는 흑백(밝기)으로 Otsu 이진화를 했다. 폰으로 모니터를 찍으면 반사 때문에 아래쪽 벨트가 밝은 하늘색으로 뜨고
과자도 거의 흰색으로 바래서, 밝기로는 둘을 구분하지 못해 아래 줄 과자를 자주 놓쳤다.
과자는 노랑·주황(따뜻한 색), 벨트는 회색·하늘색(차가운 색)이라 **색은 반사 속에서도 유지된다.**
LAB 색공간의 b 채널(파랑 ↔ 노랑)로 이진화하자 실제 촬영 76장에서 화면 끝을 뺀 사진당 박스가
아래 줄 0.74 → 1.67개, 가운데 1.80 → 2.21개, 위 1.26 → 1.58개로 늘었다. 시뮬레이터 시험 데이터 532개는 그대로 모두 찾는다.

## 과자가 아닌 덩어리 거르기 (`drop_non_cookies()`)
폰으로 모니터를 찍으면 반사 때문에 벨트 일부가 하얗게 뜬다. 화면 전체에 한 기준을 쓰는 Otsu 이진화는 이 밝은 배경을
과자로 잡아서, 큰 박스가 생기고 C3가 "불량"으로 판정한다. 시뮬레이터 과자는 모두 지름이 같다는 점을 이용해 걸러낸다.
- 면적이 그 프레임 덩어리들의 중간값보다 1.6배 넘게 크면 버린다 (반사된 배경, 붙어 버린 과자 두 개)
- 가로/세로 비가 0.4~2.5 밖이면 버린다 (벨트 테두리 띠, 시뮬레이터 화면의 노란 테두리). 반쪽 과자는 약 2.
  좌우 끝에 걸린 과자는 세로로 가늘게 잘리므로 "너무 가는 쪽"만 봐준다
- 시험 데이터 30장(과자 532개)에서 빠뜨리는 과자 없이 모두 찾는 것을 확인했다

## 박스를 과자 크기에 맞추기 (`grow_to_cookie_size()`)
폰이 모니터를 비스듬히 찍으면 한 줄 전체의 과자 가장자리가 어둡게(보라·남색) 찍힌다. Otsu는 밝은 가운데만 과자로 잡아
박스가 과자보다 작아지고, C3는 박스에서 10% 넘게 벗어난 마스크를 지우므로 과자가 잘려 정상도 `bite`·`cut`이 된다
(실측: 그 줄만 사진 단위 불량 비율 92%, 다른 줄은 31%).
- 화면 끝에 걸리지 않은 박스들의 폭·높이 중간값을 "과자 한 개 크기"로 보고, 그보다 작은 박스는 중심을 그대로 둔 채 넓힌다
- 이미 과자 크기인 박스는 그대로다. 화면 끝에 걸린 박스는 잘린 과자라 넓히지 않는다

## 혼자 확인하기
서버 없이 함수만 시험하려면 시뮬레이터 자동 캡처로 만든 `data/sim/calib/`의 프레임으로 이렇게 해 본다
(PNG도 `cv2.imdecode`로 그대로 읽힌다). 같은 번호의 `.json`에 있는 `annotations[].bbox`가 정답 박스이므로 결과와 비교할 수 있다.
```python
from app.preprocess import preprocess, detect_boxes
frame = open("../data/sim/calib/0001.png", "rb").read()
img, size, info = preprocess(frame, {"w": 1008, "h": 450})   # 크기는 같은 번호 JSON의 image.width/height
print(size, info, detect_boxes(img, size))
```
전체로 확인하려면 `docker compose up --build` 후 대시보드에서 C3가 그린 라벨이 과자 위에 뜨는지 본다.
