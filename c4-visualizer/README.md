# C4 Visualizer — 담당: 김세광

C3의 판정 결과를 원본 프레임에 그리고, 과자를 추적해 **검사선 통과 시 1회** 집계한 뒤 C1으로 보낸다.
스펙: [docs/api-spec.md](../docs/api-spec.md) 4장 ③④, 4.2

> ⚠️ **C4는 복제하지 않는다.** 추적 상태가 이 프로세스 메모리에 있어서, 여러 개로 늘리면 같은 과자의 프레임이 흩어져 집계가 틀어진다.

## 파일
| 파일 | 내용 |
|---|---|
| `app/tracker.py` | 과자 단위 집계: 추적 → 검사선 1회 집계 → 다수결 판정. **완성됨** |
| `app/draw.py` | 프레임에 결과 그리기. **완성됨** (아래 "화면 표시") |
| `app/main.py` | 서버 (C3에서 받아 추적·그리기 후 C1으로 전달). 건드릴 필요 없음 |
| `tests/test_tracker.py` | 집계 테스트: 처리 fps 1~3, 순서 뒤바뀜, 다수결, 화면 끝 과자 (`pytest`) |
| `tests/test_draw.py` | 그리기 테스트: 판정 색, 라벨 글자, 화면 끝 과자, 검사선 강조 (`pytest`) |

## 화면 표시
- **윤곽선**: `objects[].polygon` (없으면 박스). 불량 빨강(안쪽 반투명 칠) / 정상 초록 / 판단불가 노랑 / 화면 끝(`truncated`) 회색
- **라벨 2줄**: `#2 DEFECT bite` / `depth 0.12  fill 0.91`
  - 1줄: 판정 + 추정 불량 유형(`defect_type`)
  - 2줄: 오목 깊이(`depth`, 항상 표시)와 임계값을 벗어난 지표(`defect_reasons`). 판단불가면 `mask` 점수
  - 화면 끝 과자는 판정을 믿을 수 없으므로 라벨 없이 `edge`만 표시
- **검사선 통과**(`tracking.counted`): 그 프레임에서 검사선이 판정 색으로 굵어지고, 집계된 과자에 굵은 박스와 `+1 T17 DEFECT`가 뜬다.
  SAM 2는 CPU에서 1fps 미만이라 강조는 결과 프레임 1장에만 나온다.
