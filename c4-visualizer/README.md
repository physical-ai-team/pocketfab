# C4 Visualizer — 담당: 김세광

C3의 판정 결과를 원본 프레임에 그리고, 과자를 추적해 **검사선 통과 시 1회** 집계한 뒤 C1으로 보낸다.
스펙: [docs/api-spec.md](../docs/api-spec.md) 4장 ③④, 4.2

> ⚠️ **C4는 복제하지 않는다.** 추적 상태가 이 프로세스 메모리에 있어서, 여러 개로 늘리면 같은 과자의 프레임이 흩어져 집계가 틀어진다.

## 파일
| 파일 | 내용 |
|---|---|
| `app/tracker.py` | 과자 단위 집계: 추적 → 검사선 1회 집계 → 다수결 판정. **완성됨** |
| `app/draw.py` | **채울 곳.** 프레임에 결과 그리기. 지금은 텍스트, 검사선, 누적 집계, 추적 번호만 표시 |
| `app/main.py` | 서버 (C3에서 받아 추적·그리기 후 C1으로 전달). 건드릴 필요 없음 |
| `tests/test_tracker.py` | 집계 테스트: 처리 fps 1~3, 순서 뒤바뀜, 다수결, 화면 끝 과자 (`pytest`) |

## 어디부터 채우면 되나
1. **`render()`에 윤곽선 그리기** — `objects[].polygon`(0~1 좌표)에 이미지 크기를 곱해 `cv2.polylines`로 그린다.
   색: 불량 빨강 / 정상 초록 / 판단불가 노랑 (`COLORS`). 화면 끝에 걸친 과자(`truncated`)는 회색으로 구분한다.
2. 불량이면 `defect_reasons`(원형도/solidity/원 채움률 중 무엇 때문인지)를 라벨에 표시한다.
3. 검사선을 넘는 순간(`tracking.counted`)을 시연에서 눈에 띄게 표시한다 (지금은 "+1 T17 DEFECT" 글자만 있음).

## 테스트
```powershell
cd c4-visualizer
pytest
```
